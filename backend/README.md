# LifeOS Backend

Production-ready backend for LifeOS.

## Tech Stack

- Node.js
- Express 5
- MongoDB
- Mongoose
- JWT Authentication
- Cloudinary
- Multer
- Express Validator

## Features

- Authentication
- Notes
- Tasks
- Projects
- Documents
- Learning Resources
- Dashboard
- Global Search

## Folder Structure

```
src
 ├── config
 ├── constants
 ├── controllers
 ├── middleware
 ├── models
 ├── routes
 ├── services
 ├── utils
 ├── validators
 ├── app.js
 └── index.js
```

## Development

```bash
npm install

npm run dev
```
